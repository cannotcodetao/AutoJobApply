# 字段说明（这份模板本身不会被发送：以 _ 开头的文件会被脚本跳过）
# ============================================================================
#
# 【必填五项】缺任何一项，核对表会把这个目标标为「阻断」并拒绝发送
#   COMPANY   公司名称。写全称，注意集团与子公司不要混（投错主体是最常见的低级错误）
#   ROLE      投递岗位。要写清岗位序列与层级，如「研发技术类（硕士）——嵌入式方向」
#   LOCATION  工作地点。**只写首个意向城市**，这是统计口径字段
#   TO        主收件人
#   VERIFIED  邮箱来源验证。必须写「你在哪个页面、看到哪句话」。
#             写「多校转载一致」不算核实——那只是很多人抄了同一个来源，
#             不等于你亲自看到过原文。
#
# 【可选字段】
#   CC            抄送。多个地址用逗号或分号分隔。同一地址不能既在 TO 又在 CC
#   SUBJECT       邮件主题。很多企业要求「岗位+姓名+学校+专业」格式，照做
#   ATTACH        附件，分号分隔。相对路径以「attachments 目录的上级」为基准
#   LOCATION_ALT  备选城市。统计只取 LOCATION，备选写这里，避免统计口径被污染
#   BUSINESS      业务范围，15 字以内，用于统计表
#   CHANNEL       投递渠道，如「邮箱」「网申」「51job」
#   APPLIED_AT    投递日期
#   STATUS        当前状态，如「已发送」「已收到回执」「已面试」
#   NOTE          备注
#
# 【正文写作原则】
#   1. 不套模板。每封都要针对这家公司、这个岗位重写，尤其是「第三段」。
#   2. 只写能追溯到原始出处的企业描述。凡是「头部企业」「行业领先」这类
#      评价性断言，如果没有可引用的原文，就删掉。HR 一眼能看出来是套话。
#   3. 技能缺口如实说。包装出来的匹配度，会在面试第一个技术问题就崩。
#   4. 网申没提交，就不要写「已同步完成网申」，改成「我会通过贵司官方网申渠道提交」。
#   5. 正文控制在 1500 字以内。HR 平均阅读时间不到一分钟。
#
